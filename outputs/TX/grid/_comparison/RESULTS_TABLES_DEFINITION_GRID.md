# Definition grid — results tables (Texas)

Auto-generated by `pipeline/p06_results_tables.py` from the tables in
`outputs/TX/grid/_comparison/tables/`. Do not hand-edit: re-run the script.

**Grid.** 14 definitions × 4 threshold windows = **56 runs**, all 254 counties, 2015–2025.

**Held fixed across every run** (so any difference is attributable to metric, percentile, duration or window and nothing else): county-relative percentile, strict `>` comparison, walk-forward baseline (year Y judged against 1979…Y−1), year-round season, no absolute floor, IDW-gap-filled temperature.

**Reporting convention.** *Heatwave day* = one county on one date inside a qualifying run; *heatwave event* = one uninterrupted run in one county; *event duration* = integer consecutive dates. Per-county **median and range** are the substantive results; cross-county pooled totals are marked **QA** and are not headline quantities. Event duration is reported as median and max — never as a pooled average.
